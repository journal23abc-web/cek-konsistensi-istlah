Aturan Istilah 0 aturan

Tetapkan satu istilah baku dan varian yang harus dihindari. Pisahkan varian dengan koma.

Glosarium tersimpan otomatis di browser.

Tempel naskah atau dokumentasi. Pencocokan mendukung Unicode, istilah majemuk, spasi berulang, dan pelaporan lokasi baris.

Komentar dan string diabaikan. Identifier dipecah berdasarkan camelCase, PascalCase, snake_case, angka, dan akronim.

Unggah DOCX, TXT, Markdown, CSV, JSON, atau HTML. Kandidat istilah diranking dari frekuensi dan kekuatan frasa, bukan frekuensi mentah saja.

Model diunduh hanya saat fitur AI dipakai dan disimpan dalam cache browser. Tidak ada API key dan teks tidak dikirim ke server aplikasi.
